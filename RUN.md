# How to run

## Requirements

- Node.js 18+
- npm

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

Open the URL printed by Vite.

## Production build

```bash
npm run build
```

The production files will be in `dist/`.

## Preview production build

```bash
npm run preview
```

## Part B

`src/dynamic-bug.jsx` contains the broken interpolation example and both fixes.

`tailwind.config.dynamic-example.js` contains the safelist example.

## Part C

`src/components/PricingCard.jsx` demonstrates component extraction.

`src/tailwind.css` demonstrates the same styling idea using `@apply`.

## Part D

`tailwind.config.js` uses `theme.extend` for the brand palette, font, and spacing token.
